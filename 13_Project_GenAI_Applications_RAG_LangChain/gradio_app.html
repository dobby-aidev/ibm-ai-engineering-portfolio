Based on the provided document, Low-Rank Adaptation (LoRA) is a parameter-efficient fine-tuning (PEFT) technique designed for large language models. Key mechanics and advantages: 1. Frozen Backbone: The pre-trained model weights (W_0) remain completely frozen during adaptation, preventing catastrophic forgetting. 2. Low-Rank Decomposition: LoRA decomposes parameter updates into two low-rank matrices: ΔW = B × A, where the intrinsic rank r is much smaller than the hidden dimension (r ≪ d). 3. Memory & Storage Efficiency: It drastically reduces the number of trainable parameters (typically by >99%) and eliminates optimizer state storage for the frozen parameters, allowing large LLMs to be fine-tuned on modest GPU hardware without compromising accuracy.
